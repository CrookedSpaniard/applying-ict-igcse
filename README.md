# Applying ICT — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 5 Applying Information and Communication Technology, Chapter 13 Applying ICT** (book pages 182–199). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activity** (where the book has one) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including all ten chapter questions on pages 198–199).

**Part A · Data, software and layout** (pages 182–190)

1. Choosing the right software — Table 13.1, plus a “pick the software” game → ✓ Check
2. Data and information — Table 13.2 with context added row by row, an animation and a beep that only mean something with context → Activity (Considering context) → ✓ Check
3. Types of data — text (syntax), numbers (calculations, charts, alphanumeric), images (semiotics, informative text), animation (GIF frames), sound (Figure 13.1, DAC) → ✓ Check
4. Enter, organise, develop, refine, format — Table 13.3 for six applications, with spreadsheet, word processor and database products built stage by stage → ✓ Check
5. Purpose, user and layout — children vs adults, presentation/memo/poster (Figure 13.2), text wrapping, white space slider (Figures 13.4–13.5), templates (Figure 13.6) → ✓ Check
6. House styles — where content goes (Figure 13.3), corporate identity on/off, logo don’ts (Figure 13.8) → Activity (Branding) → ✓ Check
7. Font styles — serifs (Figures 13.9–13.10), low-resolution screen simulation, aesthetics and accessibility → ✓ Check
8. Test Part A (chapter questions 1, 2, 3, 5, 6, 7)

**Part B · Colour, checking and evaluation** (pages 190–199)

9. Colour choice — greyscale and monochrome (Figure 13.11), mood (Figure 13.12), an artist’s colour wheel with complementary, analogous and split-complementary schemes and hex codes (Figures 13.13–13.15) → Activity (Choosing colour patterns) → ✓ Check
10. Contrast and accessibility — contrast ratio tester (Figure 13.16), protanopia/deuteranopia/tritanopia simulation (Figure 13.17), partial sight → Activity (Accessibility of digital products) → ✓ Check
11. Checking content — spelling and grammar checker with UK/US language, suggestions, contextual and grammar errors (Figures 13.18–13.20), proofreading game → ✓ Check
12. Reviewing against requirements — iterative development cycle, Task A1 document (Figure 13.21) to mark and fix → Activity (auto-marked table) → ✓ Check
13. Strengths, weaknesses and improvements — Figure 13.22 graph improved step by step from Table 13.4 into Figure 13.23 → ✓ Check
14. Evaluation — selecting, using, effectiveness questions; useful vs weak statements; key points → ✓ Check
15. Test Part B (chapter questions 4, 8, 9, 10) · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `ai-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`AI1Z.…`) to carry on with another device.
- Nothing is sent to a server. Organisations, people and posters in the simulations are made up. Sound only plays after a click.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#colour` or `#check-checking`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
